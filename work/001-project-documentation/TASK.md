## 验收条件

1. 根 README 集中说明整体阶段；工程版本、目录职责与命令统一进入工程概览。
2. 协作规则保留阅读指引和维护要求，不再单列 Gradle 配置文件清单；专题无需统一填写任务进度与验证状态。
3. 飞行文档区分维护者提出的体验意向、待定问题、实验建议与实际实现边界，不承诺开发顺序。
4. 工作索引链接任务与结果，任务记录可用于接续和追溯；没有空白专题或重复的状态总表。
5. 文档内部链接可解析，版本摘要与实际配置一致；检查结果明确区分本次执行与历史证据。
6. `.local/` 被忽略，`work/`、`docs/` 与 `AGENTS.md` 可纳入 Git；模板原有忽略项和保留项不受影响。
7. 正式文件名为 `AGENTS.md`，当前入口不再引用旧文件；本地提交只包含项目文档和 `.gitignore`，不推送。

5. 正式启用协作规则，更新引用，检查暂存范围并创建本地提交。
