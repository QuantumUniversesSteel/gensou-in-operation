# 飞行系统

本文整理维护者既有讨论中的功能意向和待定问题。当前处于方案探索阶段，尚未形成完整功能规格；建立本文不表示飞行已被排定为下一项开发任务。

## 已提出的体验方向

希望在前期获得实用的飞行能力，并让两种题材表达具有不同用途：

| 功能意向 | 希望提供的体验 |
| --- | --- |
| 灵梦式飞行 | 偏向低速、精确的移动，辅助建造与细致操作 |
| 魔理沙式扫帚 | 偏向快速移动，服务跑图和长距离出行 |

这些名称表达题材与用途，具体获取方式、能力载体和操作规则仍待决定；目前没有承诺首版同时实现两者。

## 已提出的操作问题

维护者提出过让潜行键承担低速操作的想法，希望同时方便空中使用扳手等工具。下降方式、默认键位，以及减速与潜行交互如何共存，尚未选定。

后续设计应结合玩家实际操作讨论这些问题，而不是仅按键位是否可以绑定判断方案成立。

## 待决定的问题

| 问题 | 当前边界 |
| --- | --- |
| 能力通过什么载体生效 | 装备、饰品、背包物品、专门能力槽与永久成长都曾被讨论，尚未选定 |
| 如何进入、退出和切换飞行 | 启停方式、下降控制、两种飞行是否并存或互斥仍待比较 |
| 如何获取能力并控制使用成本 | 配方、解锁条件、能源消耗与成长机制尚未定义 |
| 如何兼容其他能力和工具 | 需要在相关实现任务中明确飞行权限归属、输入冲突及外部接口 |
| 哪些状态变化需要处理 | 实现时按范围明确死亡、重连、维度切换和能力失效后的行为 |

这些问题帮助界定后续任务，不要求在第一次操作原型之前全部定案。

## 可选的原型实验

以下是待选择的实验建议，尚未转化为实施任务：

1. 使用临时能力载体比较下降与减速的输入安排，先观察操作是否容易理解。
2. 在精细定位、空中放置方块、潜行使用工具、启停飞行等场景中观察手感与冲突。
3. 选定实验后，在对应 `TASK.md` 中约定测试环境、对比方案、验收或观察方法，再记录结果和取舍。

临时物品、测试按键和临时数值只服务实验；保留下来的控制规则再更新到本文，通用的数据或同步约定进入工程文档。
