# Gensou in Operation

一个开发中的《东方 Project》题材 Minecraft 魔法科技模组（二次创作）。项目探索特色能源、加工机制与实用能力，通过器物和交互表达题材，并以适合个人维护的规模逐步推进。

## 开发状态

项目目前处于早期原型开发阶段，已具备用于验证飞行资格的测试开关；完整飞行操纵、扫帚与其他玩法仍在设计和开发中。
